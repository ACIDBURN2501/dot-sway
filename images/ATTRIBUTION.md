# Image attribution

- **`wallpapers/frederic-church-parthenon.jpg`** — Frederic Edwin Church
  (1826–1900), *The Parthenon* (1871), oil on canvas, The Metropolitan
  Museum of Art (accession 15.30.67). The painting itself is public
  domain: Church died in 1900, so it is PD in all major jurisdictions.
  The reference photo,
  [File:Parthenon (1871) Frederic Edwin Church.jpg](https://commons.wikimedia.org/wiki/File:Parthenon_%281871%29_Frederic_Edwin_Church.jpg),
  is tagged PD-Art on Wikimedia Commons — per the WMF position, faithful
  two-dimensional reproductions of PD works are PD in the United States
  (the Commons page notes reuse *may* be restricted in other
  jurisdictions). The bundled file is a 16:9 crop of that photo, sized
  for desktop wallpaper use. It is also the default fallback wallpaper
  (`scripts/rotate-wallpaper.sh`).
- **`preview.png`** — author's screenshot of this configuration, shown in
  the README. The desktop wallpaper in it is *The Parthenon*, above.

The wallpaper is public domain and is **not** covered by the repository's
MIT license, which applies to the configuration and scripts.
